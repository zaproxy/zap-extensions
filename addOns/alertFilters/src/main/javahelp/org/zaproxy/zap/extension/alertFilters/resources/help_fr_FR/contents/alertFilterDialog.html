Boîte de dialogue « Filtre d’alerte »

Cette boîte de dialogue s’affiche lorsque vous ajoutez ou modifiez un Filtre d’alerte contextuel ou un Filtre d’alerte global

Elle comporte les champs suivants :

Portée

Il peut s’agir soit de « Global » pour un filtre d’alertes global, soit du nom d’un contexte existant. Il n’est modifiable que lorsque vous créez un filtre d’alertes à partir d’une alerte existante.

Type d’alerte

La première liste déroulante répertorie toutes les règles d’alertes actives et passives actuellement installées, ainsi que leurs références d’alertes connues. La seconde liste déroulante répertorie tous les identifiants connus (règles d’analyse et références d’alertes). Elle permet également d’en spécifier une manuellement si elle n’est pas répertoriée (par exemple, une règle personnalisée ou qui n’est pas encore installée).

Nouveau niveau de risque

Le nouveau niveau de risque à attribuer à toute alerte déclenchée correspondant aux critères définis par la règle.

URL

Une URL facultative.
Si elle est spécifiée, cette règle sera appliquée si l’URL correspond à celle d’une alerte déclenchée.

L'URL est une Regex?

Si cette option est activée et qu’une URL est spécifiée, celle-ci sera traitée comme une regex lors de sa comparaison avec l’URL de l’alerte.
Si cette option n’est pas activée, toute URL spécifiée devra correspondre exactement à l’URL de l’alerte.

Paramètre

Un paramètre facultatif.
S'il est spécifiée, cette règle sera appliquée si le paramètre correspond exactement à celui d’une alerte déclenchée.

Le paramètre est une Regex ?

Si cette option est activée et qu’un paramètre est spécifié, celui-ci sera traité comme une regex lors de sa comparaison avec le paramètre de l’alerte.
Si cette option n’est pas activée, tout paramètre spécifié devra correspondre exactement au paramètre de l’alerte.

Attaque

Un paramètre facultatif.
Si elle est spécifiée, cette règle sera appliquée si l’attaque correspond exactement à celle d’une alerte déclenchée.

L'attaque est une Regex ?

Si cette option est activée et qu’une attaque est spécifiée, celle-ci sera traitée comme une regex lors de sa comparaison avec l’attaque de l’alerte.
Si cette option n’est pas activée, toute attaque spécifiée devra correspondre exactement à l’attaque de l’alerte.

Preuve

Une preuve facultative.
Si elle est spécifiée, cette règle sera appliquée si la preuve correspond exactement à celle d’une alerte déclenchée.

La preuve est une Regex ?

Si cette option est activée et qu’une preuve est spécifiée, celle-ci sera traitée comme une regex lors de sa comparaison avec la preuve de l’alerte.
Si cette option n’est pas activée, toute preuve spécifiée devra correspondre exactement à la preuve de l’alerte.

Méthode

Une méthode facultative.
Si elle est spécifiée, cette règle sera appliquée si la méthode correspond, sans tenir compte de la casse, à celle d’une alerte déclenchée.

Activé

Si cette option est activée, cette règle sera appliquée à toutes les alertes déclenchées dans le contexte spécifié.

Filtre de test

Le bouton « Test » affichera le nombre d’alertes existantes auxquelles le filtre s’appliquera. Il est désactivé si le filtre est désactivé.

Appliquer le filtre

Le bouton « Appliquer » appliquera effectivement le filtre à toutes les alertes existantes auxquelles il s’applique. Il affichera ensuite le nombre d’alertes qu’il a modifiées. Il est désactivé si le filtre est désactivé.
