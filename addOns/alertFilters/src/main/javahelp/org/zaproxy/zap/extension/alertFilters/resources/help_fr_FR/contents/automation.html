Prise en charge du framework d’automatisation pour les filtres d’alertes

Cette extension prend en charge le framework d’automatisation.

Tâche : alertFilter

La tâche alertFilter vous permet de définir des filtres d’alertes globaux et spécifiques à un contexte.

Cette fonctionnalité est présentée dans la vidéo : ZAP Chat 08 Automation Framework Part 2 - Environment. 

  - type: alertFilter                  # Utilisé pour modifier les niveaux de risque des alertes
  parameters:
    deleteGlobalAlerts: true         # Booléen : si true, supprime toutes les alertes globales existantes ; false par défaut
    alertFilters:                    # Liste des filtres d’alertes à appliquer
      - ruleId:                      # Entier/chaîne : obligatoire, ID de la règle d’analyse ou référence de l’alerte
        ruleName:                    # Chaîne : facultatif, nom de la règle
        newRisk:                     # Chaîne : obligatoire, nouveau niveau de risque parmi 'False Positive', 'Info', 'Low', 'Medium', 'High'
        context:                     # Chaîne : facultatif, nom du contexte ; si vide, un filtre d’alertes global est créé
        url:                         # Chaîne : facultatif, chaîne à rechercher dans l’alerte ; prend en charge les variables d’environnement
        urlRegex:                    # Booléen : facultatif, si true, l’URL est une expression régulière
        parameter:                   # Chaîne : facultatif, chaîne à rechercher dans le champ de paramètre de l’alerte
        parameterRegex:              # Booléen : facultatif, si true, le paramètre est une expression régulière ; prend en charge les variables d’environnement
        attack:                      # Chaîne : facultatif, chaîne à rechercher dans le champ d’attaque de l’alerte
        attackRegex:                 # Booléen : facultatif, si true, l’attaque est une expression régulière
        evidence:                    # Chaîne : facultatif, chaîne à rechercher dans le champ de preuve de l’alerte
        evidenceRegex:               # Booléen : facultatif, si true, la preuve est une expression régulière
        methods:                     # Liste : facultatif, méthodes HTTP
