認証ヘルパー – 自動化フレームワーク対応

このアドオンは自動化フレームワークに対応しています。

ジョブ: diagnostics

diagnostics ジョブは、プランレベルでの認証関連診断の記録を開始または停止します。 記録された診断データは認証診断UIに表示され、認証レポートに含めることができます。

1つのプランに複数の diagnostics ジョブを含めることができます。 記録は enabled が true の場合に開始され、enabled が false の場合に停止（および永続化）されます。 プラン終了時に記録がオンのままになっている場合、自動的に停止され、永続化されます。 

  - type: diagnostics                  # プランレベルの診断記録を有効または無効にします
    parameters:
      enabled:                         # Bool: true の場合、診断記録を開始します。デフォルト: false

同一プラン内でこのジョブと env 認証診断（ブラウザ/クライアントの authentication.parameters.diagnostics）の両方を有効にすることは推奨されず、診断レコードが重複する可能性があります。 1つのプランにつき1つの診断メカニズムを使用することを推奨します。
