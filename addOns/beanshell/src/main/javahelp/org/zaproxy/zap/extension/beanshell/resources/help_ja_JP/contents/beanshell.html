BeanShell コンソール

BeanShell は、BeanShell スクリプトを実行するために使用できる対話型の Java シェルです。 これらのスクリプトは、Javaの構文の多くの要素を取り入れつつ、よりシンプルなスクリプト形式で記述された、Javaの簡易版です。 すべてのJavaコードは、BeanShellコードとしても有効です。
ZAPにおけるBeanShellの統合により、ZAPの関数やデータセットを使用してスクリプトを作成することができます。 これは、Webアプリケーションを分析する上で非常に強力な機能となり得ます。

BeanShellコンソール

このコンソールは「ツール」メニューから起動され、画面が上下に分割された構成になっています。上半分は対話型のBeanShellコンソール、下半分はシンプルなテキストエディタとなっています。 複雑なスクリプトを作成する場合は、Java 開発用のエディタの使用をお勧めします。 スクリプトはエディタから読み込まれ、保存および実行することができます。 BeanShellが起動すると、ZAPの以下のオブジェクトが利用可能になります。具体的には:

  • Model シングルトンを、modelという名前のオブジェクトを介して
  • 現在のサイトの SiteTree ツリーを、sites オブジェクトを介して
  • インスタンス 
    HttpSender
    を、 sender オブジェクトを介して
BeanShellは型付けが厳密ではない点に留意してください。 したがって、変数を使用する前に宣言する必要はありません。このため、スクリプトは通常のJavaよりも少し簡潔になります。 もちろん、もしその型を定義したいのであれば、そうすることも可能です。

サイトマップの使用

まずは、実用的で典型的な例から始めましょう。サイトのすべてのノードを順に巡回し、ファイルが存在するかどうかを確認します。 これを実現するスクリプトはすでに作成されていますので、「Load」を選択し、example.tree.bsh ファイルを選択してください。 [評価] をクリックする前に、まず ZAP を通じてサイトにアクセスし、ツリーにデータを反映させてください:

次に、[評価] をクリックしてエディタ内のスクリプトを実行します。エラーがなければ、以下のコマンドを実行して、スクリプトで定義されたオブジェクトの使用を開始できます: 

	t = Tree();
これにより、新しい Tree オブジェクトが生成され、その参照が t に代入されます。 
	t.find(sites.getRoot(), "index.html");
t に対して find メソッドを呼び出します。このメソッドは、最初の引数として SiteNode を、2番目の引数として検索対象のリソースを受け取ります。 この場合、ルートから開始したため、このメソッドはツリー内のすべてのノードを順に処理し、index.html ファイルを探し出します。

ヒント

unset(String) コマンドを使用して、宣言済みの変数、メソッド、またはオブジェクトの設定を解除します。 これは、現在の名前空間にあるメソッドの宣言を置き換えたい場合に便利です。 このコマンドは Object ではなく String 型の引数を取ることに注意してください。したがって、上記で使用した t オブジェクトの設定を解除するには、unset(t); ではなく unset(“t”); とする必要があります。
