Dev Add-On

An add-on to help with development of ZAP. It starts a simple test web service, which by default will be accessible via http://localhost:9091

It provides:

API Pages

Two simple OpenAPI specs, both of which require no authentication. One of the APIs described by the specs can only be accessed when authenticated.

Authentication Pages

A growing set of authentication pages, for use in testing ZAP authentication handling.

CSRF Pages

A set of pages with forms and CSRF tokens that are checked on POST requests.

HTML Pages

A set of pages which store various types of data in localStorage and sessionStorage.

Full Apps

A set of more complete apps for testing ZAP functionality end-to-end.

Fake LLM

A fake OpenAI compatible LLM, for testing add-ons which use an LLM without needing a real model. It replies to prompts with fixed responses, chosen by matching the prompt against a set of rules.

To use it add a provider to the LLM add-on, via Tools / Options / LLM, with:

  • Type: OpenAI Compatible
  • Endpoint: http://localhost:9091/llm/fake/v1 (change the host and port if you have changed them in the dev add-on options)
  • Model: fake-llm (any name will work)
  • API key: leave empty
Then select it as the default provider and model.

The rules are in the llm/fake/rules.json file in the dev add-on directory under the ZAP home directory. It is a JSON array of rules, each with:

  • match - a case insensitive regular expression, which is searched for in the last user message of the request
  • reply - the response to send, either a string or a JSON object (which is sent as a string)
The first rule that matches supplies the reply. If no rule matches then a message saying so is returned. The file is read for every request, so it can be edited while ZAP is running.

For example: 

[
  {"match": "\\bping\\b", "reply": "pong"},
  {"match": "capital of france", "reply": "The capital of France is Paris."}
]
The default rules include replies for the prompts ping, What is the capital of France? and Hello, plus a scripted AI assisted login for the /auth/simple-json/ page.

Random Pages

Dynamically generated sites for testing scalability.

Sequence Pages

A set of pages for testing the sequence add-on.
