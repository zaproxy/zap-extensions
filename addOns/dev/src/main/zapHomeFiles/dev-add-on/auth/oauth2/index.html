Mock OAuth2 Authorization Server

A mock OAuth2 Authorization Server (and a demo relying-party app), for testing the authhelper add-on's OAuth2 authentication methods against all four grant types, including PKCE.

Try the demo app (drives the full authorization_code + PKCE flow in a real browser, independently of ZAP).

Endpoints

  • Authorization Endpoint: https://authserver.oauth2.zap/authorize
  • Token Endpoint: https://authserver.oauth2.zap/token
  • Protected resource (for verification/poll URL testing): https://api.oauth2.zap/userinfo (expects Authorization: Bearer <token>)

Test clients

  • Confidential client (use with client_secret_basic or client_secret_post): client_id=test-client, client_secret=test-secret
  • Public client (use with client_auth_method: none, typically with PKCE): client_id=test-public-client, no secret

Test user

  • username = test@test.com
  • password = password123

Testing non-standard token field names

Add field_style: custom to the token request (e.g. via extraTokenParams) to have the token endpoint return accessToken/refreshToken instead of the standard access_token/refresh_token - useful for testing the accessTokenField/refreshTokenField normalization.

Example ZAP Automation Framework configuration

client_credentials

authentication:
  method: "oauth2"
  parameters:
    grantType: "client_credentials"
    tokenEndpoint: "https://authserver.oauth2.zap/token"
    clientId: "test-client"
    clientSecret: "test-secret"
sessionManagement:
  method: "header"
  parameters:
    headers: "Authorization: Bearer {%json:access_token%}"

password

authentication:
  method: "oauth2"
  parameters:
    grantType: "password"
    tokenEndpoint: "https://authserver.oauth2.zap/token"
    clientId: "test-client"
    clientSecret: "test-secret"
sessionManagement:
  method: "header"
  parameters:
    headers: "Authorization: Bearer {%json:access_token%}"
users:
- name: "Test User"
  credentials:
    username: "test@test.com"
    password: "password123"

refresh_token

First obtain a refresh token via the client_credentials/password/ authorization_code examples above (it's in the JSON response), then: 

authentication:
  method: "oauth2"
  parameters:
    grantType: "refresh_token"
    tokenEndpoint: "https://authserver.oauth2.zap/token"
    clientId: "test-client"
    clientSecret: "test-secret"
sessionManagement:
  method: "header"
  parameters:
    headers: "Authorization: Bearer {%json:access_token%}"
users:
- name: "Test User"
  credentials:
    refreshToken: ""

authorization_code (with PKCE)

authentication:
  method: "oauth2AuthorizationCode"
  parameters:
    authorizationEndpoint: "https://authserver.oauth2.zap/authorize"
    tokenEndpoint: "https://authserver.oauth2.zap/token"
    redirectUri: "http://localhost:8080/callback"
    clientId: "test-public-client"
    clientAuthMethod: "none"
    usePkce: true
sessionManagement:
  method: "header"
  parameters:
    headers: "Authorization: Bearer {%json:access_token%}"
users:
- name: "Test User"
  credentials:
    username: "test@test.com"
    password: "password123"
