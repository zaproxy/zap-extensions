Fake LLM

An OpenAI compatible endpoint which replies to prompts using pattern matching rules. Add an OpenAI compatible provider to the LLM add-on with:

  • Endpoint = http://localhost:<this port>/llm/fake/v1
  • Model = fake-llm (any name works)
  • API key = empty

The first rule whose regex is found in the last user message supplies the reply. The rules are in llm/fake/rules.json in the dev add-on directory, as a JSON array of match (regex) and reply (a string or a JSON object) pairs. The file is re-read on every request.
