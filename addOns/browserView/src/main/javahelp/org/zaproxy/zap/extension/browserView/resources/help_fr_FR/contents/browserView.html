Browser View

L’extension Browser View permet d’afficher les réponses HTML telles qu’elles seraient rendues par un navigateur.

Elle peut être sélectionnée depuis la barre d’outils de l’onglet Réponse.

Prérequis

JavaFX est requis pour utiliser cette extension. Il peut être obtenu, par exemple, auprès de Gluon HQ.

Une fois JavaFX obtenu, ZAP doit être configuré pour l’utiliser. Pour ce faire, utilisez les arguments JVM suivants en remplaçant le chemin par celui correspondant au répertoire lib de JavaFX :
--module-path /path/to/javafx/lib/ --add-modules javafx.swing,javafx.web

Si ZAP est lancé avec les scripts de démarrage par défaut, les arguments JVM peuvent être spécifiés dans le panneau des options JVM.
