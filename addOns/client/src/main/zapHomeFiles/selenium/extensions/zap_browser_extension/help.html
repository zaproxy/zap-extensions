ZAP by Checkmarx Recorder

Summary

This extension allows you to record all of the actions you take in the browser as a Zest script. It can be used to record things like authentication scripts or other complex interactions. Zest scripts can be replayed in ZAP, whether in the desktop or in automation.

When the extension is recording then a notification panel will be shown at the bottom of the page. Clicking on the "Stop and Download Recording" button will stop the recording and automatically download the recording as detailed below.

You can also stop the recording via the extension dialog and then download the recording using a filename you specify.

You can view, edit, replay, load and save the recorded script using the Script Viewer, as detailed below.

If you are using the full ZAP extension and start recording in ZAP then the Zest script will be automatically updated in the ZAP Script Console so you do not need to download it manually.

Recorder Advice and Guidance

If you are going to use the recorded script for authentication then you need to make sure that the browser will be in the same state as when it is launched from ZAP.

If the login URL is static then you can open that page before starting to record.
If the URL is dynamic then you should enter a suitable static URL in the Recorder Dialog. This URL will then be recorded in the script and the browser will handle the dynamic redirects as required.

In all cases you should start to record before dismissing any dialogs, such as cookie warnings and other disclaimers, as ZAP will need to do the same things.

It is often better to use private/incognito mode when recording so that the browser will not have any existing application state.

The 'buttons' on some modern web apps can be complicated HTML components that are sometimes hard to click on using automation. If your forms can be submitted using the RETURN key then that is often a better option to use when recording.

Recorder Dialog

Clicking on the ZAP Extension icon will display the Recorder Dialog.
This dialog has the following components:

Start / Stop Recording Button

Click to start and stop the recording.

Login URL Field

By default ZAP will start recording based on the URL in the current tab. If that is a suitable URL then you do not need to use this field.
However in some cases you might not be able to choose a suitable URL.
For example if the initial URL you need to choose automatically redirects to a one-time URL then by default the recorder would start from the one-time URL. In cases like this enter the URL the recorder should start from in this Login URL field. When you click on the Start Recording button then the extension will start recording using the URL you have given and open it in a new tab.

Script Name Field

The name of the script that the recorder will download from this dialog.

If you stop recording via the "Stop and Download Recording" button in the notification panel then the extension will automatically download the recording using an auto-generated filename.

Download Script Button

Clicking on this button will download any recorded script using the name in the above field. You must have recorded something and specified a script name.

View Script Button

Opens the Script Viewer in a new tab, as detailed below.

Config Button

Shows the extension configuration screen. In the full ZAP extension it also has the options for how to reach ZAP, which the recorder extension does not have.

Configuration Options

The configuration screen (accessible via the Config Button) has the following options:

Auto-close

When enabled, the recorded scripts will automatically close the browser window at the end of the recording.

Statement Delay

The number of milliseconds to wait between each statement when the recorded Zest script is run. The default is 1000ms (1 second). Set to 0 to disable the delay. A delay can be useful if the application being recorded cannot cope with actions being replayed much more quickly that a user will typically perform.

Help Button

Shows this screen.

Script Viewer

The Script Viewer shows the script you have recorded, one line per Zest statement, in a similar way to ZAP. Open it via the View Script Button in the Recorder Dialog. If the Script Viewer is already open then the button switches to that tab and reloads the script, which clears the results of any previous run. The recorded script can be changed, replayed, loaded and saved from here.

When you start recording from the Recorder Dialog the Script Viewer is opened in a tab behind the current one, unless it is already open. You stay on the page that you are recording, and can switch to the Script Viewer whenever you want to see the script. While a script is being recorded the Script Viewer shows each statement as it is recorded, and says that it is recording. It scrolls to follow the latest statement, unless you have scrolled up to look at something else. Statements cannot be changed or replayed while you are recording or replaying a script. Stop recording first.

Toolbar

New - discards the current script and its name, after asking for confirmation.
Load... - replaces the current script with a Zest script (.zst or .json) from your filestore. The statement delay stored in the file is not used, that is set via the configuration options. Scripts which use settings that the extension cannot keep are not loaded, so that they are not changed without you knowing. These are token definitions (parameters), authentication, a description, a prefix and a script type other than StandAlone.
Save - downloads the current script, including any changes you have made, as a .zst file. The file is named after the script name, or "script.zst" if it has no name.
Refresh - reloads the script, e.g. after recording something new.
Run - replays the script, see below.
Undo - reverses the last change you made to the script, and can be used repeatedly.
Redo - puts back a change that you have undone. It can be used repeatedly, until you make another change.
Add - adds a new statement of the type chosen in the list next to it. It is added after the selected row (click a row to select it) or at the end if no row is selected.

Editing

Hover over a row to show its buttons:
▲ ▼ - move the statement up or down.
✎ - edit the statement. Double clicking on the row does the same. This is available for the statement types Launch, Click, Send keys, Clear, Submit, Scroll to, Mouse over, Switch to frame, Close window and Comment. Unticking Enabled keeps the statement in the script but skips it when the script is run.
✕ - delete the statement, after asking for confirmation.

Changes are saved as soon as you make them. When you add or edit a statement you can choose how an element is found using a locator type (id, cssSelector, xpath, className, name, linkText, partialLinkText or tagName) and a locator. A partialLinkText locator finds the first link that has the text in it, while a linkText locator finds a link that has exactly that text.

Running a Script

Choose "in New Window" or "in New Tab" next to the Run button, then click Run. The first Launch statement opens the new window or tab and the other statements are run in it. Each row shows its result as the script runs, and the script stops at the first statement that fails. A box is shown on the page being replayed which shows the statement being run. You can drag it out of the way and it will not affect the script.

Comments, Close window statements and disabled statements are not run. Click, Send keys and Clear statements wait for their element to be enabled, and fail if it stays disabled. Switching to a frame only works for frames from the same site as the page. If the statement has a frame name then the frame with that name or id is used, otherwise the frame index is used. The Statement Delay configuration option is used between statements, if it is set.

Clicking Stop cancels the script, ending any wait straight away.

Stepping Through a Script

If you tick "Step through" before clicking Run then the first statement is run and the script then pauses. The box on the page shows the next statement with Next and Cancel buttons. The statement is only run when you click Next, and Cancel stops the script. The Script Viewer also has Next and Stop buttons while the script is paused, which can be used if you have moved to a page that is not showing the box. The Statement Delay is not used when stepping through a script.

Notification Panel

When you are recording a script then a notification panel is shown on the current browser tab. The panel will display the Zest elements recorded and then revert to showing a button: "Stop and Download Recording". Clicking on this button will stop the recording and automatically download it using a filename based on the hostname of the current page and the current date / time.

If you want to stop recording without automatically downloading the script then you can do that via the Recorder Dialog.

If the notification panel obscures part of the site that you need to interact with then you can drag it to anywhere else on the screen.
