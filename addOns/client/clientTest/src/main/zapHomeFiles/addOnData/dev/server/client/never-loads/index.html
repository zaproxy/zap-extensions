Pages which never finish loading

Each page below hangs in a different way, and links to the canary page, which loads normally. A client spider which copes with a page that never finishes loading still finds the canary page. The hanging responses only end after 10 minutes, or after the number of milliseconds given by the delay parameter (duration for the streamed ones).

  • The document never completes
  • A script never completes
  • A document keeps trickling in
  • A server-sent events stream never ends
  • A script is started but never finished
