Slow loading page

The page page only responds after a delay, which is set with the delay parameter in milliseconds (default 3000, maximum 30000).

A browser using the none page load strategy returns from the navigation to the page straight away. Until the page has loaded the browser is still on about:blank, where in Firefox localStorage is not usable.

  • 1 second
