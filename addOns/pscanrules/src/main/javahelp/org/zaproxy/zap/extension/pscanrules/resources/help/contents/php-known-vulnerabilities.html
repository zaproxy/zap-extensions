PHP Known Vulnerabilities

This page lists the known vulnerabilities (CVEs) in PHP itself which the "PHP Version with Known Vulnerabilities" alert of the Server Side Technology Version with Known Vulnerabilities passive scan rule checks disclosed PHP versions against.

The vulnerability details below are generated from the php-src security advisories when the add-on is built, so they are not translated. Vulnerabilities are listed most severe first. Versions marked as assumed to be affected are older than any version the advisory lists: older, end-of-life release branches rarely receive fixes, so they are presumed to be affected too.
