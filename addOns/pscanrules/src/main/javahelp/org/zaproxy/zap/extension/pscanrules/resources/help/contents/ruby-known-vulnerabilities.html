Ruby Known Vulnerabilities

This page lists the known vulnerabilities (CVEs) in Ruby itself which the "Ruby Version with Known Vulnerabilities" alert of the Server Side Technology Version with Known Vulnerabilities passive scan rule checks disclosed versions against.

The vulnerability details below are generated from the ruby advisory database when the add-on is built, so they are not translated. Vulnerabilities are listed most severe first. Ranges marked as assumed are those below the lowest version listed in an advisory, and the releases of old versions which the advisory lists by patch level, which the version disclosed does not say.
