Apache HTTP Server Known Vulnerabilities

This page lists the known vulnerabilities (CVEs) in the Apache HTTP Server itself which the "Apache HTTP Server Version with Known Vulnerabilities" alert of the Server Side Technology Version with Known Vulnerabilities passive scan rule checks disclosed versions against.

The vulnerability details below are generated from the Apache HTTP Server project's CVE records when the add-on is built, so they are not translated. Vulnerabilities are listed most severe first. Versions marked as assumed to be affected were listed by the project as only possibly affected.
