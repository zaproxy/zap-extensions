nginx Known Vulnerabilities

This page lists the known vulnerabilities (CVEs) in nginx itself which the "nginx Version with Known Vulnerabilities" alert of the Server Side Technology Version with Known Vulnerabilities passive scan rule checks disclosed versions against.

The vulnerability details below are generated from the nginx security advisories and CVE records when the add-on is built, so they are not translated. Vulnerabilities are listed most severe first. Ranges marked as assumed apply to nginx on Windows only, which the version disclosed does not rule out.
