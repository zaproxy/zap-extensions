## 2026-11-17
### Added
- A Shadow DOM test app (`/zest/shadow-dom`) with a link, a button and a form in (nested) open and closed shadow roots, some created after a delay.
- Automation Framework plans, one per Shadow DOM case, which run a standalone Zest script that acts on those elements and check the targets were reached.
